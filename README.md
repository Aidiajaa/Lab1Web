Praktikum 1: HTML Dasar

Repositori ini berisi latihan dasar HTML pada mata kuliah Pemrograman Web.

Ringkasan Materi & Langkah Praktikum

Struktur Dasar Dokumen HTML

Menggunakan deklarasi <!DOCTYPE html> (standar HTML5).

Elemen root <html>, <head> (judul dokumen & metadata), dan <body> (konten halaman).

Heading dan Paragraf

Heading <h1> sampai <h6> untuk hierarki judul.

Paragraf menggunakan tag <p> dengan pemisah baris bawaan browser.

Pemformatan Teks

Mencoba styling teks dasar: <b>/<strong> (tebal), <i>/<em> (miring), <mark> (sorotan), <sub> (subscript), dan <sup> (superscript).

Menampilkan Gambar

Menggunakan tag <img> dengan atribut src (lokasi file), alt (teks alternatif), dan atribut ukuran (width/height).

Hyperlink & Navigasi

Menggunakan tag <a> dengan atribut href.

Mencakup link internal (antarfile dokumen lokal) dan link eksternal (menuju URL situs lain).

List (Daftar)

Membuat daftar tidak berurutan menggunakan <ul> (bullet points).

Membuat daftar berurutan menggunakan <ol> (penomoran otomatis).

Komentar HTML

Menggunakan <!-- komentar --> untuk dokumentasi kode tanpa ditampilkan di browser.
